Abstract

Cross-Platform mobile application frameworks—such as Flutter, React Native, Apache Cordova, and .NET MAUI—have surged in popularity, allowing developers to target multiple operating systems from a single codebase. However, this flexibility introduces profound challenges for software maintenance, security auditing, and license compliance.

State-of-the-art native Android Third-Party Library (TPL) detection tools (e.g., LibScout, LibRadar, LibScan) rely on standard Dalvik/ART bytecode (classes.dex) and fail when confronted with hybrid apps, where dependencies reside inside JavaScript bundles (index.android.bundle), compiled Dart machine code (libapp.so), WebViews, or .NET assemblies. Research has been bottlenecked by the lack of high-quality, framework-diverse benchmarks.

X-TPL (Cross-TPL) provides the first verified, large-scale ground-truth benchmark mapping production hybrid Android APKs directly to their compiled third-party dependencies, supported by a fully automated and containerized curation pipeline.

Automated Curation Pipeline

Reproducible, Docker-isolated compilation system extracting verified compile-time dependency ground truths.

1. Crawling & Filtering

Uses the GitHub API via PyGithub to identify candidate repositories across Flutter, React Native, Cordova, and MAUI. Pre-filters repositories targeting latest releases or trunk commits based on build manifests.

2. Repository Analysis

Locates the topmost valid Android build directory and conservatively estimates baseline toolchain versions for Gradle, JDK, and framework runtimes. Excludes repositories with broken private dependencies.

3. Containerized Compilation

Executes builds inside dynamically generated Docker containers. Automatically bumps toolchain versions on failure and builds paired configurations: Debug, Release (with R8), and native obfuscation.

4. Ground-Truth Extraction

Extracts the final resolved lock files (package-lock.json, yarn.lock, package_config.json, packages.lock.json) alongside the architecture-specific APK binaries.

Dataset Structure & Availability

Openly accessible data repository with multiple retrieval protocols and structured framework directories.

HTTP Download
Browser & Direct Links

Direct browser exploration and single-file or zip downloads hosted on CloudLab Vault storage.

https://vault.cloudlab.zhaw.ch/vault-data/x-tpl
RSYNC Protocol
Fast & Resumable

Recommended for downloading large APK batches with differential syncing and automatic resume.

rsync -avz --progress rsync://vault.cloudlab.zhaw.ch/x-tpl ./x-tpl/
FTP Access
Bulk FTP Client

Standard FTP endpoint accessible via command-line tools (curl, wget) or GUI clients (FileZilla, Cyberduck).

ftp://vault.cloudlab.zhaw.ch/x-tpl/

├── README.txt # Dataset documentation
├── metadata.json # Root-level metadata: commit hashes, toolchain versions, build outcomes
├── ReactNative/ # React Native APKs & lock files (package-lock.json, yarn.lock)
│   └── <project_name>/ # App project folder
